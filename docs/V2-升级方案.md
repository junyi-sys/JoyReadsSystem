# 俊宜阅读 V2.0 升级方案

**版本**: 2.0
**适用对象**: 俊宜（当前 V1→V2 过渡期）及未来多学生
**核心理念**: 系统探索孩子，孩子探索世界
**设计原则**: 功能随能力阶段渐进解锁；尊重认知边界；家长可自定义升级门槛

> V3 暂不考虑。待俊宜使用 V2 后的真实反馈再确定方向。

---

## 一、等级体系与功能解锁矩阵

### 1.1 默认阈值

| 等级 | 名称 | 识字量门槛 | 阅读篇数门槛 | 解锁功能 |
|------|------|-----------|------------|---------|
| V1 | 识字萌芽 | < 100 | < 5 | 点读发音、短文生成、每日推荐 |
| V2 | 初识汉字 | ≥ 100 | ≥ 5 | 全部功能（见下方） |

V2 即可使用全部功能。等级体系为未来的多学生场景预留——不同孩子不同进度，功能按等级渐进解锁。

### 1.2 V2 完整功能清单

| 分类 | 功能 | 说明 |
|------|------|------|
| **好奇引擎** | 直接回答 | 俊宜提问 → 系统直接生成回答文章 |
| | 种子收集 | 自动扫描含"为什么/怎么/会不会"的提问，存入种子池 |
| | 种子自动生长 | 每周从种子池自动选一个问题，生成回答文章，插入阅读计划 |
| | 苏格拉底反问 | 孩子提问 → AI 先反问"你觉得呢？"→ 探测已知深度 → 再生成答案 |
| **理论库** | 录音转文字 | 录音 → whisper 转文字 → 存储 |
| | AI 归纳点评 | LLM 提炼口水话 → 鼓励性点评，不评判对错 |
| **精读计划** | 主题阅读计划 | 周日~周四，每天一篇，按主题周推进 |
| | 导读语音 | 每天一句话 TTS 导读，激发好奇心 |
| | 理解题 | 每天 1 道选择题，TTS 朗读题干 |
| | 语音归纳 | 读后录音归纳 → LLM 提炼 → 鼓励反馈 |
| **知识图谱** | 概念追踪 | 记录每个概念的掌握深度（1-4 级） |
| | 动态调难 | 根据图谱动态调整文章/回答难度 |
| **能力雷达** | 五维可视化 | 情节理解、人物分析、细节发现、联想表达、想象力 |
| **家长后台** | 多学生管理 | 查看所有学生状态 |
| | 等级设置 | 自定义每个等级的识字量/篇数门槛 |
| | 功能开关 | 手动开启/关闭精读计划、反问引导等 |
| | 种子管理 | 查看种子池、手动触发生成 |
| **多人架构** | 学生隔离 | 所有数据表含 student_id，X-Student-ID 头传递 |

### 1.3 等级自动评估 + 孩子确认

每次标记文章"已读"时触发评估：

```
total_words    = character 表 zone='ally' 的数量
total_articles = article_read_status 表 status='read' 的计数
```

满足条件时，**不由系统自动晋升，也不由家长单方决定**。流程如下：

```
系统检测到满足 V(N+1) 条件
    ↓
向孩子展示"升级预览"弹窗
    ↓
┌─────────────────────────────────┐
│  🎉 你解锁了新等级！              │
│                                 │
│  📦 新增功能：                   │
│    · 精读计划 — 每天多读5分钟     │
│    · 理解小测验 — 读完后答1道题   │
│    · AI 会反问"你觉得呢？"        │
│                                 │
│  ⏰ 每天需要多花 5-10 分钟        │
│                                 │
│  你准备好了吗？                  │
│  [ 我要升级 ]   [ 先保持现在 ]    │
└─────────────────────────────────┘
    ↓                     ↓
  孩子同意              孩子拒绝
    ↓                     ↓
  等级晋升              保持当前等级
  新功能解锁            继续用现有功能
    ↓                     ↓
  通知家长              系统继续监控，下次满足条件再弹窗
```

**设计理由**：

- 孩子是系统的使用者，他应该知道自己要面对什么
- "升级=更多时间精力"这个代价，必须让孩子自己做权衡
- 如果他还没准备好，强迫升级只会带来抵触
- 不同意不会消失——系统下次触发条件时还会再问他

### 1.4 家长自定义阈值

家长在设置页修改每个等级的识字量/篇数门槛，系统重新评估学生等级。

家长还可单独开关以下功能（不影响等级）：

- 苏格拉底反问引导（开/关）
- 种子自动生长（开/关）
- AI 归纳点评（开/关）
- 精读计划（开/关）

## 二、功能模块详细设计

### 2.1 首页改造：三卡片布局

替换原有"今日推荐"：

| 卡片 | 内容 | 数据来源 | 交互 |
|------|------|---------|------|
| 我的好奇清单 | 最近 3-5 个提问，带状态："已有回答""还在想""我的理论是" | curiosity_event | 点击跳转好奇心回答页 |
| 我的理论库 | 最近录音列表（播放按钮、日期、AI 点评标签） | theory 表 | 点击"录新理论"开始录音 |
| 阅读地图 | 累计篇数、连续天数、本周进度、能力雷达入口 | article_read_status + comprehension_record | 点击进入能力雷达页 |

底部新增：**"今天读什么？"** 按钮 → 进入精读计划或生成今日文章。

### 2.2 好奇心引擎

#### 2.2.1 回答模式

俊宜提问 → 系统直接生成回答文章。

提问入口：首页好奇清单卡片、底部导航"好奇"、语音输入。

#### 2.2.2 苏格拉底反问引导

```
俊宜问："为什么天是蓝的？"
    ↓
系统判断：是否首次接触"光的散射"相关概念？
    ↓ 是（知识图谱中无此概念）
AI 反问："你觉得是什么原因呢？先猜猜看！"
    ↓ 俊宜回答（锻炼表达）
AI 肯定 + 生成答案文章："你说对了一点！阳光里其实藏着彩虹的颜色..."
    ↓ 否（已有相关概念基础）
直接生成更深一层的答案
```

反问触发条件：
- 知识图谱中该概念掌握深度 ≤ 2，且没有同类概念记录
- 家长未关闭反问功能

#### 2.2.3 种子收集

自动扫描提问文本，含"为什么/怎么/会不会/是什么"的问题存入 curiosity_seed 表。

种子状态：`pending`（待生长）→ `growing`（生成中）→ `converted`（已生成文章）→ `skipped`。

#### 2.2.4 种子自动生长

每周六（俊宜不阅读的日子）自动触发：

```
从种子池选 1 个 pending 问题
    ↓
调用 curiosity series 模式 → 生成 300-500 字回答文章
    ↓
插入下周阅读计划的某一天
    ↓
那天导读："这是你上周问的问题哦，答案来啦！"
```

家长可关闭自动生长，改为手动触发生成。

### 2.3 理论库

#### 2.3.1 录音 → 转文字

```
前端录音（webm）→ POST /api/theory
    ↓
后端 whisper 转文字
    ↓
存入 theory 表（student_id, audio_url, transcript, created_at）
    ↓
返回转写文本给前端展示
```

#### 2.3.2 AI 归纳点评

存储完成后，异步调用 LLM：

```
LLM prompt:
"一个{age}岁孩子读了关于{topic}的文章后，录了这段话：
'{transcript}'
（孩子可能表达不完整、有口水话，这是正常的）
请用鼓励的语气：
1. 提炼孩子想表达的主要意思（1-2句话）
2. 肯定孩子说得好的地方
3. 不批评、不纠错、不打分"
```

返回结果存入 theory 表的 `ai_summary` 和 `ai_encouragement` 字段。

前端展示：转写文本 + AI 鼓励语。**不显示分数或等级。**

### 2.4 精读计划

#### 2.4.1 节奏

周日~周四，每天 1 篇。周五周六休息（或补读）。

每篇约 8-10 分钟。

#### 2.4.2 每天流程

| 步骤 | 时间 | 内容 |
|------|------|------|
| 导读 | 20 秒 | 一句话 TTS 语音，按当天精读焦点定制 |
| 阅读 | 5 分钟 | 文章含 1 个思考点标记（🤔），点读正常使用 |
| 小题 | 1 分钟 | 1 道选择题，TTS 朗读题干，点选答案 |
| 归纳 | 2 分钟 | 录音回答导读里的问题 → AI 鼓励点评 |
| 完成 | 瞬间 | 星星 + 能力雷达对应维度微调 |

#### 2.4.3 每周五个精读焦点

| 天 | 焦点 | 导读示例 | 归纳问题 |
|----|------|---------|---------|
| 周日 | 情节理解 | "读完告诉爸爸，故事里发生了什么事？" | "用'先...然后...最后...'说说这个故事" |
| 周一 | 人物动机 | "注意看故事里的人为什么那样做？" | "故事里的人为什么要那样做？" |
| 周二 | 细节发现 | "今天当小侦探，找找有意思的小细节！" | "文章里有没有让你觉得有意思的小地方？" |
| 周三 | 联想生活 | "故事里的事，你有没有见过类似的？" | "你有没有见过或经历过类似的事？" |
| 周四 | 发挥想象 | "猜猜看，接下来会发生什么？" | "如果你是作者，接下来会怎么写？" |

#### 2.4.4 主题周预设

| 周 | 主题 | 示例话题 |
|----|------|---------|
| 1 | 奇妙的自然 | 蜜蜂、蚂蚁、彩虹、大海、星星 |
| 2 | 身边的科学 | 影子、声音、磁铁、水循环、浮力 |
| 3 | 有趣的历史 | 四大发明、丝绸之路、恐龙、长城 |
| 4 | 成长的故事 | 友谊、勇气、诚实、分享、坚持 |

家长可在后台自定义主题和话题。

### 2.5 知识图谱

#### 2.5.1 概念节点

```python
class KnowledgeNode:
    student_id       # 学生
    concept          # 概念名（如"引力"、"光合作用"）
    depth            # 掌握深度 1-4
                     # 1=听过这个词
                     # 2=能简单解释
                     # 3=能举例说明
                     # 4=能迁移应用
    first_exposed_at # 首次接触时间
    last_updated_at  # 最近更新时间
    source           # curiosity | reading | theory | manual
    evidence         # 证据（如：孩子在归纳中正确使用了这个概念）
```

#### 2.5.2 深度升级规则

| 触发条件 | 深度变化 |
|---------|---------|
| 首次在文章/回答中遇到该概念 | depth: 无 → 1 |
| 在归纳中主动提到该概念 | 1 → 2 |
| 在归纳中正确使用该概念举例 | 2 → 3 |
| 在新场景中主动迁移该概念 | 3 → 4 |
| 3 个月未接触 | depth -1 |

#### 2.5.3 动态调难

文章生成时，注入知识图谱上下文：

```
已掌握的概念（放心使用）：引力(3级)、浮力(2级)
正在建立的概念（多重复）：光合作用(1级)
可引入的新概念（从种子池或相邻概念推导）：蒸腾作用
```

### 2.6 能力雷达图

五维指标，数据来源为理解题和归纳记录：

| 维度 | 数据来源 | 计算方式 |
|------|---------|---------|
| 情节理解 | 情节焦点日选择题正确率 | 最近 4 次正确率 |
| 人物分析 | 人物焦点日选择题正确率 | 最近 4 次正确率 |
| 细节发现 | 细节焦点日选择题正确率 | 最近 4 次正确率 |
| 联想表达 | 联想日 + 想象日归纳中 LLM 评分 | 1-5 分取平均 |
| 想象力 | 想象日归纳中 LLM 评分 | 1-5 分取平均 |

前端展示：五边形雷达图，每完成一周精读更新一次。

## 五、新增 API

### 等级

- `GET /api/students/{id}/level` — 当前等级 + 下一级进度
- `PUT /api/students/{id}/level-config` — 家长自定义阈值
- `GET /api/students/{id}/feature-flags` — 获取功能开关
- `PUT /api/students/{id}/feature-flags` — 更新功能开关

### 理论库

- `GET /api/theory` — 理论列表（含 AI 点评）
- `POST /api/theory` — 上传录音 → whisper 转文字 → 异步 LLM 点评
- `DELETE /api/theory/{id}` — 删除记录

### 好奇心

- `POST /api/curiosity/ask` — 提问（支持反问模式）
- `GET /api/curiosity/seeds` — 种子池
- `POST /api/curiosity/seeds/{id}/grow` — 手动触发生成
- `POST /api/curiosity/seeds/auto-grow` — 系统定时调用（每周六）

### 精读计划

- `POST /api/plan/create` — 创建计划
- `GET /api/plan/current` — 当前计划 + 进度
- `POST /api/plan/days/{day_id}/start` — 开始今日阅读
- `POST /api/plan/days/{day_id}/complete` — 提交理解题 + 归纳 → 完成
- `PUT /api/plan/settings` — 自定义主题/话题

### 知识图谱

- `GET /api/knowledge/graph` — 知识图谱数据
- `GET /api/knowledge/nodes/{concept}` — 单个概念详情

### 能力雷达

- `GET /api/stats/radar` — 五维能力数据

### 家长后台

- `GET /api/parent/students` — 所有学生概览
- `GET /api/parent/students/{id}/detail` — 单个学生详情

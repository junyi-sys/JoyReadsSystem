# Code Review Checklist

## Security Checklist
- [ ] 无硬编码的凭据或密钥
- [ ] 所有用户输入都有输入验证
- [ ] SQL 注入防护（参数化查询）
- [ ] 状态变更操作有 CSRF 保护
- [ ] 通过适当的转义防止 XSS
- [ ] 受保护端点有认证检查
- [ ] 资源有授权检查
- [ ] 安全的密码哈希（bcrypt、argon2）
- [ ] 日志中无敏感数据
- [ ] 强制使用 HTTPS

## Performance Checklist
- [ ] 无 N+1 查询
- [ ] 适当使用索引
- [ ] 在有益处的地方实现缓存
- [ ] 主线程上无阻塞操作
- [ ] 正确使用 async/await
- [ ] 大数据集分页处理
- [ ] 数据库连接池化
- [ ] 正则表达式优化
- [ ] 无不必要的对象创建
- [ ] 防止内存泄漏

## Quality Checklist
- [ ] 函数 < 50 行
- [ ] 清晰的变量命名
- [ ] 无重复代码
- [ ] 适当的错误处理
- [ ] 注释解释 WHY 而非 WHAT
- [ ] 生产环境中无 console.log
- [ ] 类型检查（TypeScript/JSDoc）
- [ ] 遵循 SOLID 原则
- [ ] 正确应用设计模式
- [ ] 自文档化代码

## Testing Checklist
- [ ] 已编写单元测试
- [ ] 覆盖边界情况
- [ ] 测试错误场景
- [ ] 存在集成测试
- [ ] 覆盖率 > 80%
- [ ] 无不稳定测试
- [ ] Mock 外部依赖
- [ ] 明确的测试名称
